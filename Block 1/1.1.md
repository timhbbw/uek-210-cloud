Wie wird der Begriff Cloud definiert?
- Cloud Computing bietet die Möglichkeit, schnell und einfach Ressourcen bereitzustellen. Gemäss NIST ist es ein Modell, das den bequemen Netzwerkzugriff auf Abruf auf einen gemeinsamen Pool von konfigurierbaren Ressourcen ermöglicht (z.B. Netzwerke, Server, Speicher, Anwendungen und Services). Diese Ressourcen können mit minimalem Verwaltungsaufwand bzw. ohne Interaktion mit dem Anbieter schnell bereitgestellt und wieder freigegeben werden.

Welches sind die 5 Merkmale einer Cloud?
- On-Demand Self Service
    - Stellt dem Nutzer die Möglichkeit selbstständig bereit, Resourcen selbst anzupassen, ohne dass ein Mitarbeitender des Providers eingreifen muss.
- Broad Network Access
    - Die bereitgestellten Ressourcen sind über das Netzwerk mit Standardmechanismen zugänglich, z.B. von Smartphone, Tablet, Laptop oder Workstation aus.
- Resource Pooling
    - Der Provider kann mehrere Nutzer gleichzeitig mit denselben Ressourcen bedienen (Multi-Tenancy). Der Nutzer weiss in der Regel nicht, wo sich die Infrastruktur genau befindet, kann aber teilweise einen gröberen Standort wählen (z.B. Land oder Rechenzentrum). Dies gibt dem Provider auch Redundanz, da er wahrscheinlich an mehreren Standorten Infrastruktur betreibt.
- Rapid Elasticity
    - Die Cloud kann sehr einfach und zum Teil automatisiert skaliert werden, d.h. Ressourcen werden bei Bedarf schnell hinzugefügt oder wieder freigegeben. Für den Nutzer wirken sie oft unbegrenzt verfügbar.
- Measured Service
    - Die Nutzung des Cloud Services wird gemessen und überwacht. Das gibt Provider und Nutzer Transparenz über den Verbrauch und ermöglicht eine nutzungsbasierte Abrechnung (Pay-per-Use).

Welche Cloud Deployment Modelle kennen Sie?
- Private Cloud
    - Die Cloud-Infrastruktur wird exklusiv von einer einzigen Organisation genutzt. Sie kann von der Organisation selbst oder von einem Dritten betrieben werden, vor Ort oder extern.
- Community Cloud (Interessensgemeinschaft)
    - Die Cloud-Infrastruktur wird exklusiv von einer bestimmten Gruppe von Organisationen mit gemeinsamen Anliegen genutzt (z.B. Sicherheitsanforderungen oder Compliance).
- Public Cloud
    - Die Cloud-Infrastruktur steht der breiten Öffentlichkeit zur Verfügung und befindet sich beim Cloud-Anbieter.
- Hybrid Cloud
    - Eine Kombination aus zwei oder mehr verschiedenen Clouds (Private, Community oder Public), die über eine Technologie verbunden sind, welche die Portabilität von Daten und Anwendungen ermöglicht.

Was sind Cloud Service Modelle?
- Software-as-a-Service (SaaS)
    - Das Programm wird in der Cloud gehostet und vom Provider betrieben. Der Nutzer hat kaum Möglichkeiten, Einstellungen an seinem Deployment vorzunehmen (höchstens begrenzte Anwendungseinstellungen).
- Platform-as-a-Service (PaaS)
    - Der Nutzer deployt seine eigene Software, kann aber gewisse Einstellungen an seinem Deployment vornehmen. Die darunterliegende Infrastruktur verwaltet der Provider.
- Infrastructure-as-a-Service (IaaS)
    - Der Nutzer kann Rechenleistung, Speicher und Netzwerk selbst auswählen und darauf direkt Software deployen. Er hat keinen Zugriff auf die Hardware selbst, kann aber das Betriebssystem etc. selber konfigurieren.

Welcher ökonomische Effekt bewirkt, dass die Kosten pro Recheneinheit bei Cloud-Anbietern durch das massenhafte Bereitstellen von Kapazitäten kontinuierlich sinken?
- Skaleneffekte (Economies of Scale)
    - Je mehr Kapazität ein Anbieter bereitstellt, desto tiefer werden die Stückkosten pro Recheneinheit. Einkauf von Hardware, Strom, Rechenzentrumsbetrieb und Automatisierung verteilen sich auf sehr viele Kunden, und der Anbieter kann diesen Kostenvorteil teilweise über tiefere Preise weitergeben.
